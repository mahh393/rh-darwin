Social narrative

The Gödel machine grew a family tree.

Jürgen Schmidhuber’s Gödel machine was a thought experiment: an AI that only rewrites itself when it can prove the change is net beneficial. Proof is impossible for most real upgrades. The Darwin Gödel Machine keeps the self-rewrite and drops the theorem — mutate, evaluate on coding benchmarks, archive the interesting survivors.

Primary source

Darwin Gödel Machine: Open-Ended Evolution of Self-Improving Agents

Jenny Zhang, Shengran Hu, Cong Lu, Robert Lange, Jeff Clune

A self-improving coding agent that iteratively modifies its own codebase — including the code that does the modifying — then empirically validates each child on SWE-bench and Polyglot. An archive of agents grows by sampling a parent and asking a foundation model for a new, interesting descendant. The search becomes a tree, not a ladder.

  • Better code-editing tools
  • Long-context window management
  • Peer-review loops between agents
  • Sandboxing + human oversight in the original experiments

The loop, on-chain

  1. Sample Pick an agent from the archive — not only the current high score.
  2. Mutate Rewrite tools, prompts, context, review. Improve the improver.
  3. Evaluate Keep what works. Interesting failures stay as stepping stones.
  4. Archive The tree branches. $DARWIN is the token that never stops iterating.
